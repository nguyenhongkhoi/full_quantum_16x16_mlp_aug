LỆNH CHẠY - QCNN S1 (bản chốt) + CNN cổ điển cùng cỡ, MNIST / Fashion-MNIST 16x16
=================================================================================
Tất cả lệnh chạy bằng PowerShell, đứng ở thư mục gốc repo (branch main). Số tham số báo theo FREE
(unitary 2 qubit 16, 1 qubit 4; xem docs\CACH_DEM_THAM_SO.txt). Mọi run: seed 0, split 50.000 train / 10.000
validation (split-seed 20260911), aug xoay +-5 độ, dịch +-0,05, dropout 0, Adam lr 1e-3, ReduceLROnPlateau
x0,5 patience 3, dừng sớm patience 10 theo val loss, tối đa 50 epoch. Chọn model theo validation;
test chính thức chỉ chạy MỘT lần cho bản chốt (bước 5).

Dữ liệu: --dataset mnist (mặc định) hoặc --dataset fashion. Tự tải vào --data-root (.\mnist_data dùng chung
cho cả hai: MNIST nằm ở .\mnist_data\MNIST, Fashion-MNIST ở .\mnist_data\FashionMNIST).

1. QCNN S1 - BẢN CHÍNH (FREE 9.389, bỏ pha 9.135; MNIST MAX val 99,10)
-----------------------------------------------------------------------
Encoder quanvolution qconv4x3 -> 3 cây level32 (row / column / morton) -> head samebasis Linear(204,10)
mỗi cây -> router lượng tử 8 qubit trộn logit. Log phải in dòng FREE parameters ... Total=9389.

# MNIST
python .\train.py --dataset mnist --front qconv4x3 --orders row column morton --side-level 32 --expert-head samebasis --dropout 0 --router quantum --router-source encoder --router-grid 4 4 --router-qubits 8 --router-layers 1 --router-ansatz se --router-init-scale 0.01 --mix logits --gate-noise 0 --balance-weight 0.01 --entropy-weight 0 --aug-degrees 5 --aug-translate 0.05 --batch-size 64 --epochs 50 --lr 1e-3 --patience 10 --seed 0 --split-seed 20260911 --device cuda --data-root .\mnist_data --out-dir .\runs\mnist_S1_samebasis | Tee-Object -FilePath .\logs\mnist_S1_samebasis.txt

# Fashion-MNIST
python .\train.py --dataset fashion --front qconv4x3 --orders row column morton --side-level 32 --expert-head samebasis --dropout 0 --router quantum --router-source encoder --router-grid 4 4 --router-qubits 8 --router-layers 1 --router-ansatz se --router-init-scale 0.01 --mix logits --gate-noise 0 --balance-weight 0.01 --entropy-weight 0 --aug-degrees 5 --aug-translate 0.05 --batch-size 64 --epochs 50 --lr 1e-3 --patience 10 --seed 0 --split-seed 20260911 --device cuda --data-root .\mnist_data --out-dir .\runs\fashion_S1_samebasis | Tee-Object -FilePath .\logs\fashion_S1_samebasis.txt
